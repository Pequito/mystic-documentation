# Getting Started

> **Documentation status:** Draft  
> **Verification:** Phase 1 pages require verification against named Mystic releases and platforms.

This section is the entry point for new and returning Mystic BBS SysOps. It is intentionally organized as a progression: understand the software, install it, create administrative access, learn the directory layout, configure it, start it, and establish a backup process before adding more services.

## Phase 1 Learning Path

### 1. What Is Mystic BBS?

Start with [What Is Mystic BBS?](What-Is-Mystic-BBS) for an overview of Mystic, MIS, MUTIL, local sessions, network services, and the major parts of a BBS installation.

### 2. Install Mystic

Follow [Installing Mystic](Installing-Mystic) for a conservative fresh-install workflow, installer concepts, ownership considerations, and initial verification.

### 3. Create the First SysOp Account

Use [Creating the First SysOp Account](First-Sysop-Account) to create a local account and elevate it to System Operator privileges before exposing network services.

### 4. Understand the Directory Structure

Read [Mystic Directory Structure](Mystic-Directory-Structure) before changing paths or building a backup plan.

### 5. Learn the Configuration System

[Mystic Configuration System](Mystic-Configuration-System) explains the main configuration areas and the difference between interactive configuration and MUTIL processing.

### 6. Start Mystic Safely

[Starting Mystic](Starting-Mystic) explains configuration mode, local login, MIS server operation, and basic startup verification.

### 7. Establish Backup and Upgrade Practices

Read [Backup and Upgrade](Backup-and-Upgrade) before performing upgrades or major structural changes.

## What Comes After Phase 1

Once the foundation is working, the next documentation phases will cover:

- Message groups and message bases
- File groups and file bases
- Menus, themes, prompts, and display files
- Users, security levels, and ACS
- MIS network services
- Events, semaphores, and logging
- FTN networking and mail processing
- Troubleshooting and recovery

## Already Running Mystic?

If the BBS is already installed and the immediate goal is FTN networking, continue with [FTN Networking](FTN-Networking).

For Mystic Programming Language development, use the dedicated [Mystic MPL Documentation](https://github.com/Pequito/mystic-mpl-docs) project.
