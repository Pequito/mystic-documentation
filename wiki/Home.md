# Mystic Documentation

Welcome to the community-maintained Mystic BBS documentation project.

Mystic BBS was created by **James Coyle**. This documentation project is an independent community effort and is not an official Mystic BBS publication.

This documentation is intended for SysOps, FTN network operators, developers, and users who want a practical reference for installing, configuring, operating, troubleshooting, and extending Mystic BBS.

## Planned Documentation Areas

### Getting Started

Installation, directory structure, initial configuration, startup, and basic administration.

### Configuration

System settings, users, security, servers, menus, themes, prompts, and common SysOp configuration.

### Message System

Local message bases, echomail, netmail, message-base configuration, and message processing.

### FTN Networking

FTN concepts, addresses and domains, AKAs, nodes, BinkP, mail flow, routing, MUTIL, FIDOPOLL, AreaFix, FileFix, and file echoes.

### File System

File bases, uploads, downloads, file areas, TIC processing, and file echoes.

### Utilities

Mystic utilities and supporting tools used for maintenance, networking, and automation.

### Administration

Events, semaphores, logging, backups, upgrades, maintenance, and operational practices.

### Troubleshooting

Structured troubleshooting for startup, networking, FTN mail, message bases, file bases, and configuration problems.

### Development

Mystic integration topics and links to the dedicated [Mystic MPL Documentation](https://github.com/Pequito/mystic-mpl-docs) project.
