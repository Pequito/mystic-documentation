# Mystic Documentation

Community-maintained documentation for Mystic BBS, including installation, configuration, FTN networking, message and file systems, utilities, administration, development integration, and troubleshooting.

This repository is intended to provide practical, organized documentation for Mystic BBS SysOps, network operators, developers, and returning users.

## Documentation

The primary documentation is maintained as wiki-style Markdown under [`wiki/`](wiki/).

Initial areas include:

- [Wiki Home](wiki/Home.md)
- [Getting Started](wiki/Getting-Started.md)
- [FTN Networking](wiki/FTN-Networking.md)
- [FTN Addressing](wiki/FTN-Addressing.md)
- [Echomail and Netmail](wiki/Echomail-and-Netmail.md)
- [Mystic FTN Mail Flow](wiki/Mystic-FTN-Mail-Flow.md)
- [Documentation Status](wiki/Documentation-Status.md)

## Scope

Planned documentation includes:

- Installing and upgrading Mystic BBS
- System and server configuration
- Message bases and file bases
- FTN networking, echomail, netmail, BinkP, MUTIL, FIDOPOLL, AreaFix, FileFix, and TIC processing
- Events, semaphores, logging, backups, and maintenance
- Menus, themes, prompts, and user configuration
- Troubleshooting and recovery procedures
- Development integration and links to dedicated scripting documentation

## MPL and MPY Development

Detailed Mystic Programming Language documentation remains in the separate project:

- [Pequito/mystic-mpl-docs](https://github.com/Pequito/mystic-mpl-docs)

This repository may explain how scripting integrates with Mystic features, but language-level MPL documentation should remain in `mystic-mpl-docs` rather than being duplicated here.

## Documentation Approach

Documentation should be:

- Practical and task-oriented
- Clear about Mystic-version differences
- Explicit about what has been tested
- Original community documentation rather than copied third-party manuals
- Structured so readers can understand both the configuration and why it works
